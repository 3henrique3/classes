2. Por que utilizamos métodos get e set ao invés de acessar os atributos diretamente?
Resposta: São métodos mais seguros e práticos para acessar e alterar atributos privados e protegidos, sem precisar ir direto no atributo da 
classe. Além disso, podemos definir formas de validação mais seguras antes desses novos valores serem atribuídos aos atributos da classe, 
no caso dos métodos setters.


3. O que acontece se tentarmos acessar personagem.__nome diretamente fora da classe?
Resposta: Ocasiona um erro, porque o atributo privado só pode ser acessado dentro da classe em que foi declarado. 


4. Qual a diferença entre variável local e variável global no contexto do sistema desenvolvido?
Resposta: As variáveis declaradas dentro de uma função e de um bloco de código só existem dentro dessa função e bloco de código, já as variáveis
criadas fora de uma função ou bloco de código podem ser acessadas em todo código, e para acessar uma variável de um escopo local fora desse
escopo local, precisa declarar que a variável é global, global variável local.

7. Modifique o método set_nivel_forca() para impedir valores inválidos.
Resposta:
def set_nivel_forca(self, nivel_forca):
        """
        Altera o nível da Força do personagem.

        O nível precisa estar entre 0 e 100.
        Aqui usamos condicionais para proteger o atributo privado.
        """
        if nivel_forca < 0 and nivel_forca > 100:
            raise ValueError("Nível da Força inválido. Use um valor entre 0 e 100.")

            self.__nivel_forca = nivel_forca
        

8. Adicione validação no método set_lado_forca().
Resposta:
def set_lado_forca(self, lado_forca):
        """
        Altera o lado da Força do personagem.

        Apenas os valores Jedi, Sith ou Neutro são aceitos.
        Aqui usamos condicionais para validar a informação.
        """
        lado_forca = lado_forca.capitalize()

        if not lado_forca == "Jedi" or lado_forca == "Sith" or lado_forca == "Neutro":
            raise ValueError("Lado da Força inválido. Use apenas Jedi, Sith ou Neutro.")

            self.__lado_forca = lado_forca
